## **FOUNDATIONAL PRINCIPLES**

### **Textual Authority Hierarchy (Non-Negotiable)**

**1. LXX (Septuagint) - PRIMARY AUTHORITY**
- Date: 250-150 BC (pre-Christian, pre-Masoretic)
- Witness: Hebrew text-type used by Apostles
- Validation: ~300 NT quotations follow LXX
- Text: Rahlfs-Hanhart Septuagint (2006)

**2. Vetus Latina (Old Latin) - SECONDARY WITNESS**
- Date: 2nd-4th century AD
- Witness: Early Latin church's understanding of LXX
- Purpose: Shows Western patristic interpretation
- Preserves pre-Jerome Latin readings

**3. Vulgate (Jerome) - TERTIARY REFERENCE**
- Date: 4th-5th century AD
- Method: Jerome translated OT from Hebrew (Hebraica Veritas)
- Use: Cross-reference, but corrected by LXX where divergent
- Text: Stuttgart Vulgate (Weber-Gryson 2007)

**4. MT Unpointed - CONSONANTAL REFERENCE**
- Date: Consonantal text ancient, standardization post-70 AD
- Use: Shows consonantal Hebrew underlying LXX
- Limitation: Vowel pointing absent - ambiguous readings

**5. MT Pointed (Niqqud) - POST-CHRISTIAN INTERPRETATION**
- Date: 6th-10th century AD (Masoretic pointing)
- Status: Post-Christian rabbinic vocalization
- Use: Noted as later interpretation, not primary authority
- Caution: May reflect anti-Christian bias in ambiguous passages

## **PROCESSING RULES**

### **Rule 1: LXX Primacy**
When LXX and MT pointed differ, **LXX wins unless:**
- LXX is demonstrably corrupt (internal Greek evidence)
- All major LXX manuscripts disagree
- NT explicitly corrects LXX reading (extremely rare)

### **Rule 2: Vetus Latina Confirmation**
When Vetus Latina supports LXX against Vulgate, this **strengthens LXX reading** as representing early church understanding.

### **Rule 3: Vulgate Alignment**
When Vulgate follows Hebrew against LXX, **check NT quotations:**
- If NT quotes LXX → Follow LXX, note Vulgate divergence
- If NT absent → Prefer LXX, note Vulgate as alternate
- If theologically neutral → Allow Vulgate reading

### **Rule 4: Niqqud as Drift**
Masoretic pointing is **interpretive, not original.** When pointed MT creates theological divergence from LXX, treat as post-Christian drift.

### **Rule 5: Consonantal Flexibility**
Acknowledge unpointed Hebrew allows multiple readings. LXX preserves one valid ancient vocalization.

## **RED TEAM VULNERABILITIES ADDRESSED**

### **Objection 1: "You're privileging translation over original"**

**Response:**
- LXX is not "just a translation" - it preserves a Hebrew text-type
- DSS confirm LXX often preserves older Hebrew than MT
- NT Apostles, inspired by Holy Spirit, quoted LXX as Scripture
- When inspired NT canonizes LXX reading, that reading IS Scripture
- We follow Apostolic witness, not post-Christian rabbinic interpretation

---

### **Objection 2: "The Masoretes preserved the text carefully"**

**Response:**
- Masoretes preserved ONE text-type carefully
- They standardized post-70 AD, after Christianity emerged
- Their pointing (6th-10th century) is interpretive, not original
- Multiple Hebrew text-types existed in Second Temple period (proven by DSS)
- LXX preserves a legitimate ancient Hebrew tradition
- Careful preservation ≠ exclusive authority

---

### **Objection 3: "Jerome knew Hebrew, why reject his work?"**

**Response:**
- We don't reject Jerome - we correct him by earlier witnesses
- Jerome's Hebraica Veritas was innovative but broke from Apostolic text
- Vetus Latina (pre-Jerome) shows early church followed LXX tradition
- When Vulgate and LXX diverge, LXX has:
  - Earlier date (250 BC vs. 400 AD)
  - Apostolic usage validation
  - Pre-Christian Hebrew source
- Jerome himself acknowledged LXX's authority for the Church

---

### **Objection 4: "This is circular - you assume NT validates LXX"**

**Response:**
- Not circular - it's hierarchical authority
- IF NT is inspired Scripture (Christian presupposition)
- AND NT quotes LXX as authoritative Scripture
- THEN NT canonizes those LXX readings as inspired
- This isn't "assuming" - it's accepting NT's own witness about its sources
- Alternative is to claim Apostles quoted faulty translations as if inspired

---

### **Objection 5: "LXX has multiple recensions"**

**Response:**
- Acknowledged - we specify Rahlfs-Hanhart as standard
- Where major LXX manuscripts diverge, we note variants
- Codex Vaticanus (B) given priority as oldest/best witness
- This is same methodology used for NT (multiple manuscripts, critical text)
- Doesn't invalidate LXX authority, just requires text-critical work

---

### **Objection 6: "Some LXX readings are clearly wrong"**

**Response:**
- Agreed - LXX is not perfect
- We don't claim LXX inerrancy, only priority
- When LXX is demonstrably corrupt (internal evidence), we note it
- But "different from MT" ≠ "wrong"
- Burden of proof is on those rejecting LXX reading, not defending it
- In ambiguous cases, LXX-supported-by-NT wins

## **IMPLEMENTATION GUIDELINES**

### **When Translating OT:**

1. Start with LXX Greek as base text
2. Check Vetus Latina for early Latin witness
3. Check Vulgate for Jerome's reading
4. Note where Vulgate diverges from LXX
5. If passage quoted in NT, NT reading is final authority
6. If no NT quote, prefer LXX unless strong evidence against
7. Note MT pointed as post-Christian interpretation where divergent

### **When Analyzing NT→OT Quotations:**

1. Find Greek NT quotation
2. Locate LXX source
3. Check if they match (usually yes)
4. Note where Vulgate OT matches or diverges
5. If Vulgate OT diverges from NT quotation, flag for LXX alignment
6. Never "correct" NT by MT against LXX

### **When Building Theological Terms:**

1. Start with Hebrew consonantal root
2. Check LXX Greek rendering(s)
3. Check Vetus Latina (if available)
4. Check Vulgate
5. Track semantic range across all four
6. Lock term if Tier 1, note if Tier 2-3
7. English descriptor captures Hebrew→Greek→Latin semantic field
