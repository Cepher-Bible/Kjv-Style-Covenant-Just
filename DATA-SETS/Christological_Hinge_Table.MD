| Hinge Type | Description |
|---|---|
| Direct name-swap | NT explicitly substitutes Ἰησοῦς where OT/LXX has κύριος (YHWH) |
| Narrative referent | NT identifies the unnamed OT actor as Christ |
| Confession pivot | OT call-on-YHWH formula re-applied to Jesus as confessional Lord |
| Creator attribution | Divine creator role (OT: YHWH) assigned to the Son |
| Knee-bow confession | YHWH-worship formula transferred to Jesus-as-Lord |
| Title transfer | Divine title belonging to YHWH applied to Christ |
| Pentecost pivot | Prophetic κύριος identified as Jesus at the hinge point of Acts 2 |
| Remnant theology | YHWH-as-remnant-preserver applied christologically |
| Taste-and-see | Psalm invitation to taste YHWH reread as tasting Christ |
| Way-preparer | Isaiah's voice prepares for YHWH; NT applies it to preparation for Jesus |
| Arm of the Lord | YHWH's arm (power) = Christ in Servant Song context |
| New covenant | YHWH declares new covenant (Jer 31); Hebrews: Jesus is mediator |
| Alpha-Omega flip | YHWH's self-designation as first and last transferred to the risen Christ |
| Ascension gift-giving | Psalm 68 ascent of YHWH re-read as Christ's ascension and Spirit-gifts |
